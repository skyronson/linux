
# Открываем iptables

## 1. Установите iptables
```
sudo apt-get update
sudo apt-get install iptables
```
## 2. Проверьте осталась ли возможность подключения по ssh к вашему серверу
Да, осталась

## 3. Почему может пропасть такая возможность?
Она может пропасть если установлена политика по умолчанию в INPUT как DROP или REJECT без исключения для SSH.

## 4. Откройте нужный порт на сервере чтобы восстановить подключение
`sudo iptables -A INPUT -p tcp --dport 235 -j ACCEPT`

- `-A INPUT` – это правило для ВХОДЯЩИХ подключений
- `-p tcp` – протокол TCP
- `--dport 214` – порт назначения
- `-j ACCEPT` – принимать входящий пакет 

## 5. Это будет udp или tcp прот?
SSH использует протокол TCP.
# Сохраняем

## 6. Сохраняются ли записанные вами правила после перезагрузки?
Нет, по умолчанию — не сохраняются.
iptables хранит правила только в памяти ядра. При перезагрузке они сбрасываются.

## 7. Как их сохранить?
Сохранить текущие правила в файл через iptables-save:

`sudo sh -c 'iptables-save > /etc/sysconfig/iptables'`


И включаем это правило, чтобы была их загрузка при старте системы:

`sudo systemctl enable --now iptables`

При работе с firewall не рекомендую отключаться от текущей сессии ssh. Лучше подключаться из другой консольки.
