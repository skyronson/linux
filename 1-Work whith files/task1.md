# Работа в консольке

## 1. Переместиться между директориями

### Перейти в домашнюю директорию
`cd ~`

### Перейти в корневую директорию
`cd /`

### Перейти в родительскую директорию
`cd ..`

### Перейти в предыдущую директорию
`cd -`

### Перейти в конкретную директорию
`cd /home/user/documents`

<br>

## 2. Вывести список файлов в директории

### Простой список
`ls`

### Подробный список с правами, размером и датой
`ls -l`

### С размерами в человеко-читаемом формате
`ls -lh`

### Показать также скрытые файлы (кроме . и ..)
`ls -A`

<br>

## 3. Вывести список всех файлов в директории

### Все файлы включая скрытые (начинающиеся с .)
`ls -a`

### Все файлы с подробной информацией
`ls -la`

### Рекурсивный список всех файлов в поддиректориях
`ls -R`

### Все файлы с сортировкой по размеру
`ls -laS`

<br>

## 4. Создать папку с подпапками

### Создать одну папку
`mkdir folder_name`

### Через абсолютный путь
`mkdir /home/user/Downloads/directory1`

### Создать несколько папок
`mkdir folder1 folder2 folder`

### Создать папку с подпапками (рекурсивно)
`mkdir -p parent/child/grandchild`

### Создать сложную структуру
    Допустим, нам нужно создать каталог ```qwerty```, в котором будут храниться следующие поддиректории:

`a` — с папками `a1`, `a2`, `a3`; <br>
`asdf` — без папок; <br>
`b` — с папками `b1`, `b2`; <br>
`c` — с папкой `c1`; <br>
`123` — без папок; <br>
`ABC` — без папок. <br>

    Для этого выполним представленную ниже команду:  
`mkdir -p /home/user/qwerty/{a/{a1,a2,a3},asdf,b/{b1,b2},c/c1,123,ABC}`

<br>

## 5.Внутри папки создать файл и записать в него что-нибудь

### Создать пустой файл
`touch filename.txt`

### Создать файл и записать текст (перезаписать)
`echo "Текст для файла" > filename.txt`

### Создать файл и добавить текст (дописать)
`echo "Дополнительный текст" >> filename.txt`

### Создать файл в определенной директории
`echo "Текст" > /path/to/directory/filename.txt`

### Создать файл с многострочным содержимым, используя перенаправление документа (Heredoc)
    В Bash и других оболочках (например, Zsh) here-document (heredoc) — это форма перенаправления, которая позволяет передавать несколько строк ввода команде.

```
[КОМАНДА] <<[-] РАЗДЕЛИТЕЛЬ
  HERE-DOCUMENT
РАЗДЕЛИТЕЛЬ
```
- Первая строка начинается с необязательной команды, оператора << и идентификатора-разделителя.

- Любая строка может быть разделителем; часто используют EOF или END.
- Если разделитель не в кавычках (' или "), выполняется подстановка переменных, подстановка команд и т.д.
- Использование <<- заставляет оболочку удалять начальные табуляции из here-документа (пробелы не удаляются).
- Последняя строка должна содержать только разделитель (без    начальных пробелов или символов в конце).

<br>

```
cat > filename.txt << EOF
Строка 1
Строка 2
Строка 3
EOF
```
<br>

## 6. Переместить файл из одной директории в другую

### Переместить файл
`mv file.txt /target/directory/`

### Переместить файл с переименованием
`mv oldname.txt /target/directory/newname.txt`

### Переместить несколько файлов
`mv file1.txt file2.txt /target/directory/`

### Переместить все txt файлы
`mv *.txt /target/directory/`

<br>

## 7. Скопировать файл из одной директории в другую

### Скопировать файл
`cp file.txt /target/directory/`

### Скопировать файл с переименованием
`cp oldname.txt /target/directory/newname.txt`

### Скопировать рекурсивно (для директорий)
`cp -r source_directory/ /target/directory/`

### Скопировать с сохранением атрибутов
`cp -p file.txt /target/directory/`

<br>

## 8. Переименовать файл

### Переименовать файл
`mv oldname.txt newname.txt`

### С помощью команды rename
`rename 's/old/new/' *.txt`

<br>

## 9. Сравнить содержимое файлов

### Простое сравнение
`diff file1.txt file2.txt`

### Сравнение с контекстом
`diff -u file1.txt file2.txt`

### Побайтовое сравнение
`cmp file1.txt file2.txt`

### Сравнение с игнорированием пробелов
`diff -w file1.txt file2.txt`

### Визуальное сравнение (если установлен vimdiff)
`vimdiff file1.txt file2.txt`

<br>

## 10. Отсортировать содержимое файла

### По возрастанию (алфавитный порядок)
`sort filename.txt`

### По убыванию
`sort -r filename.txt`

### Числовая сортировка
`sort -n filename.txt`

### Числовая сортировка по убыванию
`sort -nr filename.txt`

### Удалить дубликаты при сортировке
`sort -u filename.txt`

### Сохранить результат в файл
`sort filename.txt > sorted_file.txt`

<br>

## 11. Удалить все папки и файлы

### Удалить файл
`rm filename.txt`

### Удалить несколько файлов
`rm file1.txt file2.txt file3.txt`

### Удалить все txt файлы в текущей директории
`rm *.txt`

### Удалить папку рекурсивно
`rm -r folder_name`

### Удалить папку без подтверждения
`rm -rf folder_name`

### Удалить всё в текущей директории
`rm -rf *`

### Удалить всё 
`rm -rf /`

Некоторые опции команды `rm` для изменения работы:
- `-f` — позволяет принудительно удалять файлы без подтверждения.
- `-i` — запрашивает подтверждение перед каждым удалением.
- `-v` — показывает на экране, что делает команда `rm`.
