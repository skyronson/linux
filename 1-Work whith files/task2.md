# Перенаправляем

## 1. Как работают команды >,>>?

\> — перенаправляет stdout (стандартный поток вывода) команды в файл, перезаписывая его содержимое.

`echo "Привет" > файл.txt   # файл.txt будет содержать "Привет"`

\>> — перенаправляет stdout в файл, добавляя в конец (не удаляя старое содержимое)

`echo "Мир" >> файл.txt     # добавит "Мир" в конец файла.txt`

## 2. Что такое перенаправление ввода? stderr, stdout;

- stdin (стандартный ввод, файловый дескриптор 0): откуда программа читает данные (обычно клавиатура).
- stdout (стандартный вывод, дескриптор 1): куда программа выводит обычные данные.
- stderr (стандартный поток ошибок, дескриптор 2): куда программа пишет сообщения об ошибках.


## 3. Вывести содержание файла не используя текстовые редакторы;

`cat файл.txt`

Покажет всё содержимое файл.txt в терминале

## 4. Создать файл с содержимым не используя текстовые редакторы;

`echo "Содержимое" > файл.txt`

или с помощью cat в интерактивном режиме:
```
cat > файл.txt <<EOF
Строка 1
Строка 2
EOF
```

## 5. Перенаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

- `stdout → stderr`:
```
команда 1>&2
```
- `stderr → stdout`:
```
команда 2>&1
```

**Примеры на `ping`:**
```
# stdout -> stderr
ping -c 1 127.0.0.1 1>&2
# stderr -> stdout
ping -c 1 no-such-host 2>&1
```

Сначала `stdout` уходит в файл, затем `stderr` отправляется туда же, куда направлен `stdout`.

## 6. Чем отличаются stdout и stderr
- `stdout` — для нормального вывода программы (результаты работы).
- `stderr` — для диагностических сообщений, предупреждений, ошибок.

Они независимы: можно перенаправить одно, не затрагивая другое.

По умолчанию оба выводятся в терминал, но при перенаправлении (> файл) только stdout перенаправляется, а ошибки всё равно идут в терминал — это удобно для отладки.

## 7. Что такое stdin?
`stdin` — стандартный поток ввода, обычно связан с клавиатурой/терминалом, но может быть перенаправлен из файла или из другой команды.

## 8. Как отправить весь вывод команды в пустоту?
**Только stdout в “никуда”:**
```
cmd > /dev/null
```

**И stdout, и stderr в “никуда”:**
```
cmd > /dev/null 2>&1
```
