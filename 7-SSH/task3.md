# Ключики

## 1. Что такое ssh ключи и зачем они нужны?
SSH-ключи — это пара криптографических ключей:
- Приватный ключ (private key) — остаётся у юзера, никому не передаётся. Это «цифровая подпись».
- Публичный ключ (public key) — копируется на сервер, используется для проверки подписи.
Они нужны для аутентификации в SSH без передачи пароля по сети и для удобного входа.

## 2. Как их создать? 
С помощью утилиты ssh-keygen:
`ssh-keygen -t тип_ключа -b длина -f путь/к/файлу -C "комментарий"`

## 3. Создайт пару публичный/приватный ключ ed_25519, где они хранятся?
![img.png](images/9.png)

Публичный ключ хранится в `~/.ssh/id_ed25519.pub`

Приватный – в `~/.ssh/id_ed25519`

## 4. Скопируйте публичный ключ на ваш сервер, в каком файле он будет храниться?
Копирую публичный ключ командой `ssh-copy-id linux`

Он хранится в файле: `~/.ssh/authorized_keys`

## 6. Запретите подключение с паролем для всех пользователей, оставьте только с помощью ключа.
Заходим в конфигурационный фвйл

```
sudo vi /etc/openssh/sshd_config
```

И меняем `PasswordAuthentication` на `no`

И перезапускаем систему

```
systemctl restart sshd
```
