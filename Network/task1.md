## 6. Что такое ip адрес?
IP-адрес — уникальный числовой идентификатор устройства в TCP/IP-сети.
Позволяет маршрутизировать пакеты между узлами.

## 7. Для чего нужны маршруты?
Маршруты определяют, куда отправлять сетевые пакеты в зависимости от адреса назначения.

## 8. Что за протокол arp?
ARP (Address Resolution Protocol) — протокол уровня канального слоя (L2), который сопоставляет IP-адрес MAC-адресу в локальной сети.

## 9. Что такое dhcp?
DHCP (Dynamic Host Configuration Protocol) — протокол для автоматической выдачи IP-адреса, маски подсети, шлюза, DNS-серверов.

## 10. Что такое dns?
DNS (Domain Name System) — система преобразования доменных имён в IP-адреса.

## 11. Как называется один из протоколов синхронизации времени?
NTP (Network Time Protocol)

## 12. Что такое широковещательный запрос, зачем он нужен?
Широковещательный запрос — это запрос, который предназначен для получения всеми компьютерами сети. Для этого запрос посылается на специальный IP или MAC-адрес. 

Зачем нужен широковещательный запрос:
- Выяснение адресов соседей. Узел не обязан знать канальные и сетевые адреса всех своих соседей, а пытается выяснить их при помощи широковещательного запроса. Например, на основе этого механизма работает протокол ARP, который позволяет узнать MAC-адреса по известному IP-адресу.
- Экономия ресурсов. Если бы не было широковещательного запроса, узлу пришлось бы обращаться к каждому узлу в канальной среде по отдельности.
- Отправка пакетов всем хостам в сети. Обычно это локально подключённая сеть.

## 13. Какой адресс является широковещательным?
Последний адрес подсети (определяется маской). Например, если адрес сети равен 192.168.0.0, маска подсети 255.255.255.0, то широковещательный адрес будет 192.168.0.255.

## 14. Какие ещё параметры можно задать сетевой карте?
MTU (Maximum Transmission Unit), MAC-адрес, скорость, duplex-режим, состояние (up/down).

## 15. Что такое маска подсети? зачем она нужна?
Маска подсети — битовая маска, которая разделяет IP-адрес на:

- Сетевую часть (одинаковая для всех в подсети),
- Хостовую часть (уникальная для каждого устройства).

Пример:
- IP: 192.168.1.50
- Маска: 255.255.255.0 (или /24)
- Сеть: 192.168.1.0
- Диапазон хостов: 192.168.1.1 – 192.168.1.254
- Широковещательный: 192.168.1.255
